# Agentic AI: A Practical Learning Guide

Editorial edition: 17 October 2026.

Open [index.html](index.html) in a browser to use the interactive guide. The file also works directly from disk.

To publish it, follow [GITHUB-PAGES.md](GITHUB-PAGES.md). The clean `github-pages` folder contains the files to upload. Hosting needs no build step, server, API key, or external JavaScript library.

## Where to begin

If you are new to AI, read Chapters 1 to 3, then Chapter 6. Each chapter opens with its main idea, an everyday example, and a learning outcome. Use the glossary when a term is unfamiliar. Code examples can be left for a later visit.

If you are ready to build, follow the 12-week plan. It develops one simulated support agent through tool design, retrieval, evaluation, efficiency, recovery, and security. Plan for 8 to 10 hours a week and allow more time if you are also learning programming.

Use [the Markdown guide](STUDY-GUIDE.md) as the editable content source and [the workbook](PRACTICE-WORKBOOK.md) for the exercises and project specifications. The HTML includes both in full.

Progress and notes stay in your browser. Use Export progress and Import progress to transfer them between browser profiles or site addresses. Clearing browser data can remove saved progress.

The guide includes conceptual code and project specifications. It does not include a production-ready agent application. The objective is to develop skills you can demonstrate through your own implementations and measured results.
